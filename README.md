# Selera Malaysia

## Project Description

Selera Malaysia is a Malaysian food ordering website designed to introduce and showcase popular Malaysian food and drinks through a simple and user-friendly web interface. The website features a selection of local dishes and beverages, allowing visitors to explore menu items and interact with the website.

## Features

- **Welcome Section:** Introduces Selera Malaysia and its purpose.
- **Featured Menu:** Displays Malaysian food and beverages with images, prices, and descriptions.
- **Interactive Menu Descriptions:** Users can show or hide individual food descriptions.
- **Light/Dark Mode:** Allows users to switch between light and dark themes.
- **Contact Form:** Includes input validation for name, email, and message.
- **Dynamic Date and Time:** Displays the current date and time in the footer.
- **Responsive Design:** Designed to work across different screen sizes, including mobile devices.
